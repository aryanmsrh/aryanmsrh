### § 1. Premise

$$\text{Problem Formulation} \xrightarrow{\quad\text{Mathematical Model}\quad} \text{Vectorized / Compiled Execution} \xrightarrow{\quad\text{Empirical Verification}\quad} \text{Ground Truth}$$

Mathematics dictates the analytical bounds of a problem; systems programming brings it into executable reality. My objective is to formulate systems from their foundational axioms before wrapping them in convenience libraries.

- **Foundations:** Linear Algebra, Stochastic Calculus, Multivariable Optimization, Numerical Analysis.
- **Engines:** Vectorized numerical pipelines in Python (NumPy); low-latency, cache-conscious logic in C++.

### § 3. Verified Implementations

#### I. [Neural Engine / Pure NumPy](https://github.com/aryanmsrh/neural-engine-numpy)
A deep learning architecture formulated and programmed strictly using multi-dimensional array operations in Python &amp; NumPy.
- **Analytical Basis:** Chain rule matrix equations: $\frac{\partial L}{\partial W^{[l]}} = \frac{1}{m} dZ^{[l]} (A^{[l-1]})^T$.
- **Validation:** Evaluated on MNIST handwritten classification; achieves **97.2% test accuracy** across 109,386 parameters without automatic differentiation packages.

#### II. [Interactive Canvas Mathematics](https://aryanmsrh.github.io)
A zero-dependency browser-based laboratory showcasing geometry in motion.
- **Analytical Basis:** Linear coordinate mappings $T(v) = Av$, orthogonal basis transitions, and harmonic waves.
- **Performance:** Hardware-accelerated Canvas API rendering at **60 FPS** with zero build toolchain overhead.

#### III. [Competitive Algorithms Archive](https://github.com/aryanmsrh/competitive-programming)
Rigorous algorithmic solutions with asymptotic guarantees across Codeforces and LeetCode.
- **Analytical Basis:** Graph theory, dynamic programming over states, number-theoretic primes, fast modular exponentiation.
- **Objective:** Minimal CPU cycle waste and strict memory boundaries.
